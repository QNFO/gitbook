# 1+1=多元主義

## 確実性の解体と、多元的宇宙の設計

**著者:** Rowan Brad Quni-Gudzinas **所属:** QNFO **連絡先:** rowan.quni@qnfo.org **ORCID:** 0009-0002-4317-5604 **ISNI:** 0000 0005 2645 6062 **DOI:** 10.5281/zenodo.17250642 **公開日:** 2025-10-02 **版:** 2.0

本論文は、$1+1=2$ という命題を第一原理から証明するという課題を再解釈することで、20世紀初頭の数学における基礎の危機を検討する。目的は、単一の巨大な基礎を求める探求から、形式体系からなる多元的宇宙を現代的に受け入れるに至るまでの基礎的思考の変遷をたどることである。歴史的かつ哲学的分析を通じて、本論文はホワイトヘッドとラッセルの _『プリンキピア・マテマティカ』_、そしてその最終的な失敗は、非論理的公理への依存のために、数学を純粋論理へ還元できなかったことにある。

***

### 1.0 基礎的問い: 単純な和を形式体系の試金石として再解釈する

命題 $1+1=2$ は、数学哲学の核心にある二重性を示している。一方では、それは自明な事実であり、その真偽が疑われることのない単純な計算である。他方では、それを計算によってではなく、考えうる最も基本的な原理からの論理的導出によって正当化するという深遠な課題を表している。この再解釈は、問題を算術の練習問題から、形式体系の整合性と表現力を厳密に検討するものへと移す。目標は和の結果を確認することではなく、この結果を必然的な定理として導き出せるような論理的枠組みをゼロから構築することである。その最も単純に見える真理を証明しようとする努力に体現された、この絶対的確実性の追求は、すべての形式体系に内在する限界と直接向き合うことを強いる。

20世紀初頭に数学の基礎の危機として知られる時期は、むしろ失敗ではなく、絶対的確実性というこの幻想そのものを極めて生産的に解体したものとして理解されるべきである。素朴集合論におけるパラドックスの発見と、それに続く形式体系の限界の露呈は、数学が単一の巨大な基礎の上に立っているわけではないことを明らかにした。この認識は学問の崩壊を招いたのではなく、むしろその成熟を促し、数学的知識が安全であるとはどういうことかを再調整することを迫った。この危機は、真理の唯一の究極的土台を求める哲学的探求の終わりであり、数学を多元的事業として捉える、より洗練された理解の始まりを告げた。

### 2.0 ロジシズムの野心: 巨大な基礎を求める探求

基礎づけの課題は、最も有名にはロジシズムという哲学学派によって引き受けられた。ロジシズムは、数学が全体として純粋論理の一分野であることを示すことで、揺るぎない基礎を与えようとした。

#### 2.1 数学を純粋論理へ還元するという目的

ロジシズムの中心命題は、すべての数学的概念は論理的用語のみを用いて定義でき、すべての数学的定理は論理の公理だけから導出できる、というものであった。論理は、真理が普遍的で必然的であり、経験的観察や誤りうる人間の直観に依存しないとみなされたため、確実性の究極の土台と考えられた。もし数学が論理の複雑な拡張であることを示せるなら、その真理はこの絶対的確実性を継承することになる。

#### 2.2 _『プリンキピア・マテマティカ』_ ロジシズム計画の体現として

ロジシズムの構想を実現しようとする最も徹底的かつ決定的な試みは、アルフレッド・ノース・ホワイトヘッドとバートランド・ラッセルによる三巻本の著作 _『プリンキピア・マテマティカ』_ （1910–1913年）であった。この記念碑的な著作は、還元主義的プログラムを完全な形式的詳細において実行しようとした。そのためには、あらかじめ想定された数学的対象を退け、それらを論理的原始概念から構成しなければならなかった。数は、等濃なクラスのクラスとして巧みに定義された。$1$ は単一要素集合と一対一対応させうるすべてのクラスのクラスとなり、$2$ は二要素集合と一対一対応させうるすべてのクラスのクラスとなった。加法は、互いに素な集合の和集合を通じて、これらのクラスに対する操作として再定義された。$1+1=2$ の証明が悪名高く長大かつ複雑であるのは、この野心の直接的帰結であった。著者たちは単なる算術的事実を証明していたのではなく、その事実を絶対的な論理的厳密さで述べるために必要な概念宇宙全体を構成していたのである。

### 3.0 苦い勝利: ロジシズム計画の解体

一方で _『プリンキピア・マテマティカ』_ その技術的な目的は達成されたが、この達成には大きな代償が伴った。この計画は、複雑な場当たり的枠組みや非論理的公理を導入せざるを得ず、最終的にはその中心的な哲学的主張を損なった。この内在的な弱点は、後にゲーデルの定理による外的な判定によって確認され、ロジシズムの成功がピュロスの勝利であったことを明らかにした。

#### 3.1 論理的純粋性の妥協: 非論理的公理の導入

数体系の構成を完成させるため、ホワイトヘッドとラッセルは、論理の自明な真理ではない公理を導入せざるを得なかった。この行為は、数学が _純粋な_ 論理へ還元されるというロジシズムの中核的主張を損なった。

* **無限公理:** 自然数の無限集合の存在を保証するために、体系は、宇宙に無数の異なる対象が存在することを仮定しなければならなかった。これは論理の真理ではなく、現実の性質についての実質的な経験的主張である。これにより、この計画は論理的演繹から、形而上学的仮定に依存する仮説的体系へと変貌した。
* **還元可能性公理:** 彼らの分枝型理論（パラドックスを避けるために設計された枠組み）の実際上の致命的制約を克服するために、著者たちはこの公理を導入した。これは、ラッセル自身を含めて、内在的な論理的正当化を欠いているとして強く批判された。その唯一の擁護は道具的なものであり、これがなければ体系が機能しなかったという点にあった。これは数学を機能させる修正パッチとして働いたが、純粋な論理的導出という哲学的約束を破ってしまった。

#### 3.2 外的な判定: ゲーデルの不完全性定理

の内在的な哲学的弱点は _『プリンキピア・マテマティカ』_ 1931年のクルト・ゲーデルの研究によって決定的に形式化された。彼の不完全性定理は、当初の定式化におけるロジシズムの野心全体が、単に難しいというだけでなく、論理的に実現不可能であることを証明した。

* **第1不完全性定理:** 数学的文を数として符号化するという見事な手法（ゲーデル数付け）を用いて、ゲーデルは、実質的に「この文はこの形式体系の内部では証明できない」と述べる自己言及的文を構成した。体系が無矛盾であるなら、この文は真であるが証明不可能でなければならず、体系が必然的に不完全であることを示している。
* **第2不完全性定理:** 彼はさらに、算術を含むほど強力な形式体系は、その体系自身の無矛盾性を証明するためには用いられないことを示した。これは、自己完結し自己検証する基礎というロジシズムの夢に対する最後の一撃であった。

これらの発見は、数学のすべてを包含し、かつ自らの枠組みの内部で健全であることを証明できる単一の形式体系を作るという希望を打ち砕いた。この危機は、痛みを伴いながらも必要な、数学が自らの構造的境界を自覚する過程であった。

### 4.0 生産的な分化: 新しい基礎的多元主義

この時期の真の遺産は失敗ではなく、数学的思考の成功した、きわめて生産的な分化であった。激しい議論によって、さまざまな数学的実践に潜在していた哲学的コミットメントが明示化され、その結果、明確で整合的かつ価値ある複数の基礎プログラムが現れた。元の問い、「数学の唯一の真の基礎とは何か」は、不適切であることが示された。それは、より微妙で実践的な一連の問い、「特定の公理集合を採用するとどのような結果になるのか？」および「与えられた課題に最も適した基礎はどれか？」に置き換えられた。 _その_ 数学の唯一の真の基礎とは何か」という問いは不適切であることが示された。それは、より微妙で実践的な一連の問い、「特定の公理集合を採用するとどのような結果になるのか？」および「どの基礎が与えられた課題に最も適しているのか？」に置き換えられた。

#### 4.1 構成的内容のスペクトル: 表現力と検証可能な確実性のトレードオフ

出現したさまざまな基礎体系は、構成的内容のスペクトル上に配置できる。片端には、すべての証明がアルゴリズムであり、すべての対象が明示的に構成される、最大限の構成的確実性の領域がある。もう一方の端には、抽象的で非構成的な手法によって無限構造に関する強力な定理を証明できるが、直接的な計算的意味を犠牲にする、最大限の表現力の領域がある。

#### 4.2 抽象性と確実性のピラミッド

このスペクトルは、抽象性と確実性のピラミッドとして視覚化でき、その基底は最大限の抽象性を、頂点は最大限の確実性を表す。このモデルは、絶対的真理をめぐる競合理論としてではなく、想像できるものと構成できるものの間にある認識論的トレードオフを管理するための異なる戦略として捉え直すことで、ばらばらな学派を統一する。

**4.2.1 頂点: 構成的／計算可能な中核（直観主義）**

ピラミッドの頂点には、L.E.J. ブラウワーの直観主義に根ざした構成数学の世界がある。ここでは、無限領域に対して排中律 ($P \lor \neg P$) のような原理を退けるため、表現力は制限される。直観主義者にとって、ゴールドバッハ予想のような命題は必ずしも真でも偽でもなく、構成的な証明または反証が見つかるまで未決定のままである。しかし、得られる確実性は絶対的である。各証明は直接に計算アルゴリズムに対応し（この関係はカリー＝ハワード対応によって形式化される）、存在証明は対象を構成する方法を与える。真理は検証と同義である。

**4.2.2 中間層: 形式体系（形式主義）**

中間層は、ペアノ算術のような形式体系によって占められ、ダヴィッド・ヒルベルトの形式主義の遺産を表している。ヒルベルトの計画は、 _対象理論_ （数学の形式的ゲーム）と _メタ理論_ （有限的で、直観的に確実な推論 _について_ のゲーム）

**4.2.3 底部: 古典的／無限的宇宙（集合論）**

ピラミッドの底部は、現代集合論の古典的かつ無限的な宇宙、通常は選択公理を伴うツェルメロ＝フレンケル集合論（ZFC）である。これはロジシズム計画の射程を継承するものではあるが、その哲学を継承するものではない。その表現力は最大であり、非構成的推論と実在無限の力を全面的に受け入れる。例えば選択公理は、対象を構成する方法を何も与えずにその存在を証明することを可能にし、バナッハ＝タルスキーのパラドックスのような強力だが直観に反する結果をもたらす。ここでの確実性は実践的なものであり、その無矛盾性は深い信頼と広範な成功の問題ではあるが、有限的手段で証明することはできない。

### 5.0 厳密な工学分野としての基礎選択

基礎的多元主義の受容は、数学的実践に新しい方法論を必要とする。旧来の枠組みは哲学的であり、唯一の真の基礎を求めていた。新しい枠組みは建築的・工学的であり、特定の仕事に対して適切な道具を選び、異なる体系の間に形式的な橋を架けることに焦点を当てる。

#### 5.1 領域適合性の原則

基礎体系は問題領域に合わせなければならない。ソフトウェア検証のように各ステップが計算可能でなければならない場合には、ピラミッドの頂点にある構成的型理論が適している。抽象解析や位相幾何学では、基底にある ZFC の力がしばしば必要となる。量子世界の論理が古典的でないかもしれない理論物理学では、研究者はトポス理論のような代替的基礎を探究する。このように、基礎体系の選択は信仰の行為ではなく、制約付き最適化問題として扱われる。

#### 5.2 体系的妥当性の実証としての命題の再証明

現代の文脈では、命題 $1+1=2$ を証明することはもはや大事業ではない。それは体系の仕組みを示す日常的な実演であり、ピラミッドの異なる層の中で、その独自のアプローチと哲学的基盤を示すために行われる。

*   **ペアノ算術における導出:** この高次の体系は、後者関数 ($1 := S(0)$、$2 := S(S(0))$) によって数を公理的に定義する。証明は、加法の再帰的定義に基づく簡潔な5段階の導出であり、抽象的な構造的推論の力を示している。

    $$
    \begin{align*}
    1 + 1 &= S(0) + S(0) && \text{(By definition of 1)} \\
    &= S(S(0) + 0) && \text{(By axiom 2 of addition: $n + S(m) = S(n+m)$)} \\
    &= S(S(0)) && \text{(By axiom 1 of addition: $n + 0 = n$)} \\
    &= 2 && \text{(By definition of 2)}
    \end{align*}
    $$
* **ZFC における導出:** この低次の体系は、可能な限り最も原始的な概念である空集合 ($0 := \emptyset$、$1 := {\emptyset}$、$2 := {\emptyset, {\emptyset\}}$) から数を構成する。証明は、濃度1の2つの集合の互いに素な和集合が濃度2の集合になることを示すことを含む。これは、この体系がほとんど何もないところから数学全体の建造物を構築できる力を示している。

この2つの証明のどちらを選ぶかは、望まれる抽象度と基礎的深さに基づく工学的判断である。

#### 5.3 厳密性の新基準: 計算支援による形式主義

の野心の真の後継者は _『プリンキピア・マテマティカ』_ 単一の著作ではなく、対話型定理証明系（例: Coq, Isabelle, Lean）の現代的エコシステムである。これらの道具は、ヒルベルトの完璧な形式的厳密さという夢の実践的実現を表している。彼の哲学的プログラムは失敗したものの、証明から誤りと曖昧さを排除するという目的は、ホワイトヘッドとラッセルが想像できた以上の程度で実現された。機械検証された証明は、検証可能な計算対象であり、これまで到達した中で最高水準の論理的厳密さを表している。この技術により、数学者は基礎選択という工学的実践を完全な精度で遂行できる。

### 6.0 結論: 決定的な証明から検証可能な体系へ

$1+1=2$ を第一原理から確定的に証明しようとする長い知的旅路は、単一の絶対的基礎を求める探求から、検証可能な形式体系の宇宙を創造し、その中を航行するという、より洗練された計画へと発展してきた。

#### 6.1 数学全体を証明することの不可能性

ロジシズム計画の壮大な野心は、いまや不可能な目標であると理解されている。ゲーデルの研究の永続的な遺産は、数学的に興味深いほど強力な基礎は必然的に不完全であり、自らの無矛盾性を示すこともできない、という認識である。これにより、単一の巨大な基礎を探すことは放棄され、基礎的多元主義が受け入れられることになった。数学は単一の領土ではなく、相互に接続しつつも異なる形式的な島々からなる群島であると認識されたのである。

#### 統一に向けた終わらない探求

安定した基礎的多元主義の確立は、基礎的事業が終わったことを意味しない。統一への衝動は数学の本質である。ホモトピー型理論（HoTT）のような強力な現代的候補は、ピラミッドの異なる層の間の隔たりを埋めようとする。HoTT は、幾何学、論理、計算と深い関係をもつ単一で整合的な枠組みを与え、論理的同値を数学的同一性とみなす一価性公理のような強力な新原理を導入する。このようなプログラムの存在は、統一された基礎を求める探求が終わったのではなく、進化したことを示している。基礎の危機の究極的な遺産は、基礎的事業そのものを、静的な真理の土台を求める哲学的探求から、数学的現実の複数の厳密な概念を設計し統合していく動的で継続的な過程へと変容させたことにある。

### 付録

#### 付録A: ペアノ算術における導出

**定理:** 命題 $1+1=2$ は、一階ペアノ算術の形式体系の内部で導出可能な定理である。

**1.0 体系と基礎**

この導出は、一階ペアノ算術（PA）の形式体系の内部で行われる。この証明に必要な基礎は次のとおりである:

* **1.1 原始記号:**
  * 定数記号 $0$（ゼロを表す）。
  * 単項後者関数 $S(n)$（$n$ の直後にくる数を表す）。
* **1.2 数字表記の定義:** 標準的な数字表記は、原始記号 $0$ と $S$ によって定義される。
  *   **定義1:** 数字 $1$ は $0$ の後者として定義される。

      $$1 := S(0)$$
  *   **定義2:** 数字 $2$ は $1$ の後者として定義される。

      $$2 := S(1)$$

      定義1を用いて代入すると、これは次と同値である:

      $$2 := S(S(0))$$
* **1.3 加法の公理:** 加法という二項演算は、任意の自然数 $n$ と $m$ に対して次の2つの公理で定義される:
  * **公理A1（基底場合）:** $n + 0 = n$
  * **公理A2（再帰的ステップ）:** $n + S(m) = S(n + m)$

**2.0 形式的導出**

導出は、式 $1+1$ から始め、定義と公理を適用してそれを式 $2$ に変換する等式の連鎖として進む。

1.  初期式を示す:

    $$1 + 1$$
2.  式の両項に対して、数字 $1$ の定義（定義1）を代入する:

    $$1 + 1 = S(0) + S(0)$$
3.  式 $S(0) + S(0)$ に加法の第2公理（公理A2）を適用する。ここで $n$ は $S(0)$、$m$ は $0$ である:

    $$S(0) + S(0) = S(S(0) + 0)$$
4.  括弧内の部分式 $S(0) + 0$ に加法の第1公理（公理A1）を適用する。ここで $n$ は $S(0)$ である:

    $$S(S(0) + 0) = S(S(0))$$
5.  式 $S(S(0))$ に数字 $2$ の定義（定義2）を代入する:

    $$S(S(0)) = 2$$

**3.0 結論**

導出の各段階における等式の推移性により、次の同値の連鎖が確立された:

$$1 + 1 = S(0) + S(0) = S(S(0) + 0) = S(S(0)) = 2$$

したがって、命題 $1+1=2$ は、ペアノ算術の定義と公理から形式的に導出される。

#### 付録B: ゼルメロ＝フレンケル集合論における導出

**定理:** 命題 $1+1=2$ は、ゼルメロ＝フレンケル集合論（ZFC）の形式体系において導出可能な定理である。

**1.0 体系と基礎**

導出は ZFC の内部で行われ、すべての対象は集合である。

* **1.1 原始記号:**
  * 基本的な対象は **集合**.
  * 基礎となる定数は **空集合**であり、$\emptyset$ と表され、その存在は空集合の公理によって保証される。
* **1.2 数字の定義（フォン・ノイマン順序数）:** 自然数は集合として構成され、各数はそれ以前のすべての数の集合である。
  *   **定義1（0）:** $0$ は空集合として定義される。

      $$0 := \emptyset$$
  *   **定義2（1）:** $1$ は $0$ の後者として、すなわち $0$ を含む集合として定義される。

      $$1 := S(0) := 0 \cup \{0\} = \emptyset \cup \{\emptyset\} = \{\emptyset\}$$
  *   **定義3（2）:** $2$ は $1$ の後者として、すなわち $0$ と $1$ を含む集合として定義される。

      $$2 := S(1) := 1 \cup \{1\} = \{\emptyset\} \cup \{\{\emptyset\}\} = \{\emptyset, \{\emptyset\}\}$$
* **1.3 濃度と加法の定義:**
  * **定義4（濃度）:** 有限集合 $A$ の濃度を $|A|$ と表すと、それは $A$ の要素と $n$ の要素の間に全単射が存在するような唯一の自然数 $n$ である。
  *   **定義5（濃度の加法）:** 2つの基数 $\kappa$ と $\mu$ の和は、2つの **互いに素な** 集合 $A$ と $B$ の和集合の濃度として定義される。ここで $|A| = \kappa$、$|B| = \mu$ である。

      $$\kappa + \mu := |A \cup B| \quad \text{where } |A|=\kappa, |B|=\mu, \text{ and } A \cap B = \emptyset$$

**2.0 形式的導出**

導出は、濃度1の2つの互いに素な集合を構成し、それらの和集合を取り、その結果の集合の濃度が2であることを示すことによって進む。

1. **代表集合を選ぶ:** 基数1に対応する2つの集合 $A$ と $B$ を選ぶ。$A := {\emptyset}$、$B := \{{\emptyset\}}$ とする。これらの集合の存在は対の公理によって保証される。
2. **濃度を確認する:**
   * 集合 $A = {\emptyset}$ はフォン・ノイマン順序数 $1$ である。$A$ と $1$ の間には自明に全単射が存在する。したがって $|A| = 1$。
   * 集合 $B = \{{\emptyset\}}$ と集合 $1 = {\emptyset}$ の間には全単射が存在する。したがって $|B| = 1$。
3. **互いに素であることを確認する:** A の唯一の要素は $\emptyset$ である。B の唯一の要素は ${\emptyset}$ である。正則性公理により、$\emptyset \neq {\emptyset}$ である。したがって、A と B は要素を共有せず、その共通部分は空集合である: $A \cap B = \emptyset$。
4.  **和集合を計算する:** 和集合の公理より:

    $$A \cup B = \{\emptyset\} \cup \{\{\emptyset\}\} = \{\emptyset, \{\emptyset\}\}$$
5. **和集合の濃度を求める:** 得られる集合は ${\emptyset, {\emptyset\}}$ である。定義3により、この集合はまさにフォン・ノイマン順序数 $2$ である。この集合とそれ自身の間には自明に全単射が存在する。したがって、$|A \cup B| = 2$。

**3.0 結論**

濃度1の2つの互いに素な集合 $A$ と $B$ を構成した。$|A|=1$、$|B|=1$ であることを示した。それらの和集合の濃度 $|A \cup B|$ が2であることを示した。濃度加法の定義（定義5）より:

$$1 + 1 = |A \cup B| = 2$$

したがって、命題 $1+1=2$ は、ゼルメロ＝フレンケル集合論の定義と公理から形式的に導出される。
